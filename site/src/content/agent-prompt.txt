Queue an email campaign for me with TinyMails. Do not start it.

TinyMails is a local Gmail outbox for agents: https://github.com/Gauthi3r/tinymails

1. Check that it is running: curl -s http://127.0.0.1:3210/api/health
If it is not installed, clone the repository, run "npm install" and then "npm start". It needs Node.js 22 or newer.

2. Use its MCP tools if you have them: list_accounts, queue_campaign, send_test. If you cannot use MCP in this session, use the local API shown below each step. The MCP address, to add for next time: http://127.0.0.1:3210/mcp

3. List the Gmail accounts: list_accounts, or GET http://127.0.0.1:3210/api/accounts
If none is listed, stop and ask me to connect one in TinyMails Settings. If several are listed, ask me which one to send from.

4. Ask me for the contact list and the message if I have not given them to you. The message is plain text and can use {firstName} and {company}. A contact with no first name gets "there", and one with no company gets "your company".

5. Queue the campaign with queue_campaign. Without MCP, send one request, without an Origin header:
POST http://127.0.0.1:3210/api/campaigns
Content-Type: application/json
{"name": "...", "subject": "...", "body": "...", "accountIds": ["<id from step 3>"], "dailyCap": <the account's dailyCap>, "delayMinSeconds": <the account's>, "delayMaxSeconds": <the account's>, "recipients": [{"email": "...", "firstName": "...", "company": "..."}]}
Send every contact as it is. TinyMails removes invalid, duplicate and do-not-contact addresses itself. The campaign arrives paused, and "excluded" lists each refused address with its reason. If a request fails, show me the error and stop.

6. Send me the test: send_test, or POST http://127.0.0.1:3210/api/campaigns/<campaign id>/test-send
It sends the real email to my own Gmail address only, and it unlocks Start.

7. Tell me how many recipients were queued, list every excluded address with its reason, and tell me the test is in my inbox. Then stop.

I will read the test and press Start myself in TinyMails. Never call start_campaign or /start.
